# Тестовые источники и права

Для публичного benchmark не скачиваются целые главы современной манги или scanlation-репозитории без явного разрешения правообладателя.

Текущий chapter-like benchmark генерируется локально скриптом `scripts/generate_manga_benchmark.py`: фон, панели, пузыри и русский текст создаются самим проектом. Это позволяет проверять OCR без массового копирования чужой главы.

Для реальных тестов поддерживаются два безопасных варианта:

1. пользователь предоставляет свои страницы или подтверждает права на них;
2. используется источник с явно указанной лицензией Public Domain/CC BY/CC0, а лицензия и ссылка записываются в этот файл.

После получения разрешённых страниц их можно положить в отдельный локальный каталог и прогнать тем же `evaluate_manga_benchmark.py`, не коммитя чужие изображения в публичный репозиторий.
