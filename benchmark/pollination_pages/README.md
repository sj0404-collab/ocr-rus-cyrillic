# Original AI-generated Russian manga-style benchmark

Эти страницы созданы специально для OCR-тестирования с помощью image-generation инструмента, а не скачаны из существующей манги или scanlation-репозитория.

- `*_art.png` — оригинальный чёрно-белый фон с персонажами и пустыми пузырями;
- `final/*.png` — те же страницы с точно наложенным русским текстом;
- `final/manifest.json` — эталонная разметка текста для каждой страницы.

Страницы предназначены для оценки детектора пузырей, порядка чтения, распознавания кириллицы, цифр и пунктуации. Они не являются заменой реальному набору фотографий/сканов из APK.
