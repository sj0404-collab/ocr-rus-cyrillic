# PC smoke test

Дата запуска: 2026-08-20.

## ONNX + Python consensus

- 20 синтетических русских слов;
- несколько шрифтов DejaVu Sans/Serif;
- 20/20 exact match после визуального decode и консервативной русской постобработки;
- CER: 0.000 на этом маленьком чистом наборе;
- для трудных слов система честно оставляет `certain=false`, даже если итоговая строка после словарной проверки совпала.

## TFLite conversion check

- recognizer: fixed `[1, 48, 320, 3]`, output `[1, 40, 165]`;
- detector: fixed `[1, 736, 736, 3]`;
- float32 recognizer TFLite и ONNX дали одинаковую argmax-последовательность на проверочном crop;
- максимальное абсолютное различие logits на проверочном crop: около `7e-6`;
- сырой TFLite CTC decode дал 18/20 exact на словах; два случая (`ешё`, `мягкИх`) исправлены тем же консервативным русским post-processing в Python baseline.

Это smoke test, а не обещание 90% на произвольной камере. Для реальной оценки нужны размеченные кадры из будущего APK: чистая печать, наклон, шум, низкое разрешение, манга/пузыри и разные шрифты.
