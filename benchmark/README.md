# Benchmark

Здесь будут сценарии и результаты сравнения OCR-движков.

## Формат набора данных

Для каждого изображения рекомендуется хранить:

```text
sample-001.png
sample-001.txt       # эталонный текст UTF-8
sample-001.json      # метаданные без персональных данных
```

Минимальные поля метаданных:

```json
{
  "id": "sample-001",
  "source_type": "scan",
  "script": "Cyrillic",
  "language": "ru",
  "resolution_dpi": 300,
  "font_or_period": "modern"
}
```

## Метрики

- **CER** — доля ошибок на уровне символов;
- **WER** — доля ошибок на уровне слов;
- **latency** — время обработки одного изображения;
- **layout score** — отдельная ручная или автоматическая оценка блоков, колонок и таблиц.

Исходные документы с персональными данными и неясными правами не добавляйте в публичный репозиторий.
