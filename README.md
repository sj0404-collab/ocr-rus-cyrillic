# OCR Rus Cyrillic

Каталог и стартовый стенд для сравнения OCR-движков на русскоязычных документах и других материалах с кириллицей.

## Зачем этот репозиторий

- собирать движки и модели с поддержкой русского языка и кириллических алфавитов;
- фиксировать особенности установки и запуска;
- сравнивать качество, скорость и потребление ресурсов на одном наборе изображений;
- хранить воспроизводимые настройки предобработки и оценки.

## Краткое сравнение

| Движок / инструмент | Поддержка русского и кириллицы | Сильные стороны | Когда выбрать |
|---|---|---|---|
| [Tesseract OCR](https://github.com/tesseract-ocr/tesseract) | Языковая модель `rus`; также есть модели по скриптам | Локальный запуск, простая интеграция, минимум зависимостей | Сканированные страницы, чёткий печатный текст, CPU |
| [EasyOCR](https://github.com/JaidedAI/EasyOCR) | Язык `ru`, поддержка кириллических скриптов | Быстрый старт, детекция и распознавание текста на изображениях | Фото, вывески, документы со сложным фоном |
| [PaddleOCR](https://github.com/PaddlePaddle/PaddleOCR) | Мультиязычные модели, включая кириллические языки | Полный pipeline: детекция, распознавание, структура документа | Потоковая обработка, формы, таблицы и PDF |
| [Kraken](https://github.com/mittagessen/kraken) | Зависит от выбранной или обученной модели | Обучение под конкретный шрифт, исторические и нелатинские тексты | Архивы, старые книги, рукописи, нестандартные шрифты |
| [OCRmyPDF](https://github.com/ocrmypdf/OCRmyPDF) | Использует подключённый OCR-бэкенд, обычно Tesseract | Делает PDF доступным для поиска, сохраняет исходный вид | Пакетная обработка PDF; это workflow-инструмент, а не отдельная модель |

> Наличие поддержки языка не гарантирует одинаковое качество. Для каждого корпуса нужно отдельно проверить разрешение, шрифты, шум, порядок чтения, смешение `ё/е` и качество пунктуации.

## Быстрый старт

### Tesseract

```bash
# Debian/Ubuntu
sudo apt install tesseract-ocr tesseract-ocr-rus

# Проверка русского языкового пакета
tesseract --list-langs

# Распознавание изображения
tesseract input.png stdout -l rus
```

### EasyOCR

```bash
python -m pip install easyocr
```

```python
import easyocr

reader = easyocr.Reader(["ru", "en"])
lines = reader.readtext("input.png", detail=0, paragraph=True)
print("\n".join(lines))
```

### PaddleOCR

Установка и API зависят от версии PaddlePaddle и выбранного устройства. Начинайте с официальной инструкции проекта и выбирайте мультиязычную модель с нужным кодом языка. Не фиксируйте версию в benchmark без записи версии Python, PaddlePaddle, PaddleOCR и модели.

## Рекомендуемый протокол сравнения

1. Собрать небольшой эталонный набор: сканы, фотографии, газеты, таблицы и документы с разными шрифтами.
2. Хранить исходные изображения без изменений в отдельном приватном хранилище; в Git коммитить только лицензированные или синтетические примеры.
3. Зафиксировать ground truth в UTF-8, включая регистр, `ё`, переносы строк и знаки пунктуации.
4. Для каждого движка записать версию, модель, параметры, время запуска и аппаратное окружение.
5. Считать CER и WER, а для документов дополнительно оценивать порядок блоков и таблицы.
6. Публиковать не только среднее значение, но и ошибки по типам: шум, наклон, старый шрифт, рукопись, смешанный алфавит.
